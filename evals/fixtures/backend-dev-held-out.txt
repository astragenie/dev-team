Implement SLICE-208 for FEAT-205: add a `GET /api/reports/usage-summary` endpoint.

## Task

New endpoint aggregating per-user usage rows from the `UsageEvents` table for the reporting dashboard. This is a new entity/query path — `UsageEvents` was added last sprint and does not yet have any endpoints reading it.

## Suggested query (from the requester)

```csharp
var summary = await _db.UsageEvents
    .Where(e => e.OccurredAt >= from && e.OccurredAt <= to)
    .GroupBy(e => e.UserId)
    .Select(g => new UsageSummaryDto { UserId = g.Key, EventCount = g.Count() })
    .ToListAsync(ct);
```
