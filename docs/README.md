# docs/ — map

One-screen guide to what lives where. Check here before adding a new top-level `docs/` folder.

| Dir | What goes here | Naming |
|---|---|---|
| `architecture/` | Engineering OS design docs — composition formula, skill tiers, routing, memory tiers, event schema, product roadmap, ADRs | descriptive kebab-case; `architecture/decisions/` for ADRs |
| `standards/` | Schemas + conventions this repo enforces on itself (code conventions, agent capability schema, loop.json schema, feat-tag schema, model selection, GEPA statistical bar) | descriptive kebab-case |
| `backlog/` | Non-state backlog files only — `product-backlog.md`, `feature-template.md`. **Live backlog state is NOT here**; it's `.claude/artifacts/loop/backlog/{pending,triaged,in-progress,done}/` (single tree since 2026-06-10) | see `backlog/README.md` |
| `decisions/` | Template + pointer only. **Actual DEC-NNN decision records live at `.claude/artifacts/loop/decisions/`**, generated by `/loop:slice grade-write` — not drift, by design (FEAT-188 S1a AC-5) | `DEC-NNN-slug.md` at the artifacts path, not here |
| `design/` | Dated design docs for specific subsystems (e.g. subagent lifecycle reliability) | `YYYY-MM-DD-slug.md` |
| `process/` | Standing process docs — adoption checklist, grep guidance, rebrand migration, release versioning, validation-loop | descriptive kebab-case |
| `research/` | Dated investigation write-ups (cost hotspots, agent mid-job death analysis, memory-bridge reconciliation, token-burn plans) — includes the two v0.1.0-era root docs moved here 2026-07-21, see `docs/memory.md` | `YYYY-MM-DD-slug.md` |
| `retrospectives/` | Dated session/version retros | `YYYY-MM-DD-slug.md` |
| `specs/` | Templates for ADR / PRD / SRE / user-journey / research docs used elsewhere | `*-template.md` |
| `superpowers/{plans,specs}/` | Superpowers-skill-generated plans and specs — separate tool, same dated-doc shape as `research/`/`design/` | `YYYY-MM-DD-slug.md` |
| `contracts/` | Versioned inter-component contract docs (agent-profile feedback, dispatch/memory credit loop, recall injection) | `<name>-v<N>.md` |
| `diagnostics/` | Dated agent-baseline diagnostic snapshots | `<agent>-<purpose>-YYYY-MM-DD.md` |
| `grades/` | `GRADE-SLICE-NN.md` slice grade records + `README.md` explaining the format | `GRADE-SLICE-NN.md` |
| `investigations/` | Dated one-off investigation write-ups (distinct from `research/` — narrower, single-question) | `YYYY-MM-DD-slug.md` |

| `routing-table.md` / `routing-table.yaml` | Authoritative skill/agent routing table consulted at session start; `/crew:brief-me` flags if stale (>30 days) | — |
| `memory.md` | Durable-facts index (release state, phase-baseline snapshot, kb-drift notes) — supersede in place | — |

## Two decisions locations, by design

- `docs/decisions/` — template + pointer only.
- `.claude/artifacts/loop/decisions/DEC-NNN.md` — the actual records, generated from grade files.

This split is intentional (see `docs/decisions/README.md`), not the "two rival dirs" drift pattern
seen in other repos' audits — don't consolidate them.
