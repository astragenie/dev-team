# DEC-020: Multi-slice FEATs need --keep-feature-open on intermediate closes

## Context

Options: (a) one giant slice — rejected (too much blast radius), (b) per-slice close with manual feature restore until last slice, (c) treat each slice as its own micro-FEAT decomposition. Chose (b) for this slice with manual restore.
