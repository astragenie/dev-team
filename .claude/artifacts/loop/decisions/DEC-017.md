# DEC-017: Hook flow = exported core (`hooks/lib/<name>.ts`) + thin entry shim

## Context

Each per-tool hook (check-redundant-read, check-subagent-return, record-read-content, preflight-shell) previously required a `node --experimental-strip-types` spawn per test (~120 spawn tests × 0.3–0.6s on Windows). Extracting the flow into a unified core `run<Name>Hook(raw: string, env: NodeJS.ProcessEnv) => Promise<string | null>` lets tests `import` the core and assert in-process. Entry shims keep stdin/stdout/exit semantics byte-identical for the runtime contract.

### Positive

- positive: ~120 spawn tests collapse to in-process imports — large wall-clock lever after WS1 (suite 115.9s → 21.1s).
- positive: `record-read-content` loses its mid-flow `process.exit(0)` (repo rule 6 compliance).
- positive: 469 LOC of spawn-test boilerplate deleted.

- negative: test helper signatures now type as `NodeJS.ProcessEnv` (includes `undefined`) instead of `Record<string, string>`. Caught + fixed during typecheck.
