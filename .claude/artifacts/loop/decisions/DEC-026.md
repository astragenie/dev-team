# DEC-026: Slim-down targets measured against preserved-section floor

## Context

When proposing a line cap for an agent/skill slim-down slice, the spec-writer MUST sum the preserved-section line ranges first and set the cap at that floor + reasonable headroom (≤15%). Setting caps relative to "desired reduction" without measuring the floor produces unreachable targets that get amended mid-slice and erode product_completeness scoring. The FEAT-158 "≤200" target was set against stale 278-line count when current was 369, and the irreducible preserved sections alone are ~290 lines.

- negative: requires spec-writer to do upfront line-counting (cheap; one Bash command).
- negative: aspirational targets get traded for measured floors — caller may push back on "why not 200?". Answer is now "because the floor is N + 15%".
