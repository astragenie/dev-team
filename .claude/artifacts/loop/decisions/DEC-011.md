# DEC-011: Use stdin.resume() + return instead of process.exit(0) in async hooks

## Context

`process.exit(0)` inside async main() with deep import chains crashes libuv on Windows (Node v24 + --experimental-strip-types). Using `process.stdin.resume()` then `return` allows natural process exit, avoiding the race condition.
