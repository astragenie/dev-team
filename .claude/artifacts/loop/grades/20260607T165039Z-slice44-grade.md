## Lessons

- Windows libuv crash from `process.exit(0)` in async hooks with 3+ imports: replace with `process.stdin.resume(); return` for gate-off paths
- `exactOptionalPropertyTypes` means `prop: null` in test fixtures must become `prop: undefined` or omit entirely — `null` is not `undefined`
- `noUncheckedIndexedAccess` requires `!` on every array index read; use `for...of` to avoid index patterns entirely
- Default function params typed as `null` (e.g., `sourceProject = null`) infer type as `null` — must cast `null as string | null` or add explicit param type annotation
- Empty array `[]` in untyped function → `never[]`; fix with cast or return type annotation
- `Dirent` comes from `"node:fs"`, not `"node:fs/promises"`
