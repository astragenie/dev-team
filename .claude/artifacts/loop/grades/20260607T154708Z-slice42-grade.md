## Lessons

- exactOptionalPropertyTypes ripples through every interface that uses `?: string` — when migrating, bulk-update all affected interfaces to `?: string | undefined` BEFORE fixing call sites, not after
- Builder agents claim success based on IDE diagnostics which are stale; always run `npx tsc --noEmit` in a fresh shell to verify actual compiler state
- Fix builder dispatched twice still left errors; direct lead fixes are faster for systematic interface changes
- `flags.feature ?? undefined` produces `string | undefined` which is NOT assignable to `?: string | null` — use `flags.feature` (already `string | null`) or `?? null`
