## Lessons

- Light-tier combined gate works end-to-end, including the unhappy path: combined verdict was overturned on lead audit (namespace misread), validation_stale badge applied, fix bounce escalated to the FULL ladder per the WS2 conflict rule — AC-WS2-2 and AC-WS2-5 exercised live, not simulated.
- Combined-gate reviewers need namespace context: the agent counted `.claude/artifacts/loop/decisions/DEC-*` as the `docs/decisions/` convention and approved the wrong path. Decision-record namespace map (loop DEC-NNN vs repo ADR-NNN) belongs in the reviewer-validator prompt or a skill.
- Registry caveat: a newly shipped agent type (crew:reviewer-validator) is dispatchable only after session restart; pilot used a faithful fallback (claude agent carrying the agent prompt verbatim).

## Decisions

### DEC-016: Repo ADRs live at docs/architecture/decisions/ADR-NNN; DEC-NNN namespace is loop-owned

**Rationale**: loop grade-write mints sequential DEC-NNN ids in .claude/artifacts/loop/decisions/; a repo doc claiming the next DEC id collides with the loop's allocator. ADR-NNN under docs/architecture/decisions/ keeps human architecture records and loop retrospective decisions in disjoint namespaces.

**Consequences**:
- No id collisions between loop-minted decisions and authored ADRs
- docs/decisions/ remains template/README only; future ADRs go to docs/architecture/decisions/
