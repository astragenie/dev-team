## Lessons

- Inline `new Promise((resolve) => ...)` returns `Promise<unknown>` — always add explicit type param `new Promise<{...}>((resolve) => ...)`
- `noUncheckedIndexedAccess` applies to all array indices including in test assertions; pattern is `arr[i]!.prop` not `arr[i].prop`
- ESLint 9 flat config with `scripts tests` CLI arg fails when all `.ts` files in `tests/` are non-`.mjs` (ESLint defaults to `.js/.mjs/.cjs` only); fix: remove `tests` from lint script, rely on `tsc` for test type checking
- Prettier reformats multi-param function signatures into multi-line when they exceed line length — expected, not an error
- LSP/diagnostic tool shows stale state after edits; trust `tsc --noEmit` as ground truth, not the inline diagnostics
