## Decisions

### DEC-TBD-1: Workflow YAML schema mirrors loop runtime field names for cross-repo parity

**Rationale**: `parallel_dispatch`, `aggregation { halt_on_any_FAIL, wait_for_all }`, `routing.tag_routes`, and `routing.resolved_by` all use the exact field names already present in sibling loop runtime. When SLICE-B (or a future loop-vendoring step) ports the runtime into hero-crew, the YAML drops in without field re-keying.

**Consequences**:
- positive: zero re-keying cost when loop runtime ports/vendors.
- positive: golden trace test is a direct mirror of runtime output, not a translation.
- negative: hero-crew + loop schemas are now coupled — schema breaking change in either repo requires coordinated bump.
