## Decisions

### DEC-006: Recommendation-only, not automated dispatch-time enforcement

**Rationale**: Automating model selection (lead inspects slice spec, picks model, passes to Agent tool) would require new dispatch-prompt scaffolding + override surface. Recommendation-in-run-brief preserves user control + is dogfoodable now.

**Consequences**:
- positive: ships now, no CLI/Agent-tool plumbing required
- positive: cost-report.modelMix reveals rule adherence forward
- negative: rule depends on lead reading + applying its own subsection consistently
- negative: no test catches drift — soft enforcement
