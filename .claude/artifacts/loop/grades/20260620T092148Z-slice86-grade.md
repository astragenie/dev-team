## Lessons

- **Repo's actual `capabilities:` shape is richer than FEAT-160 proposed.** FEAT body suggested flat `capabilities: [surface:ui, stack:react, ...]`. Real shape is structured: `capabilities: { role: [...], surfaces: [...], stacks: [...], concerns: [...], lens: [...], scopes: [...], priority: <n> }`. The repo's shape is better — typed dimensions enable per-dimension query without a tag parser. Registry consumed the existing shape directly.
- **Empty-query semantics matter for CLI ergonomics.** First implementation returned `[]` on no-filter queries (defensive). Test fixture caught this — operator expects `crew agent-route` (no flags) to list everything. Changed to: empty query returns all entries (no filter to reject).
